# 第一部分：数据结构考点

## 1.1 数组 ★
- **连续内存**，支持 O(1) 随机访问（按下标）
- 插入/删除 O(n)（要移动元素）
- 查找：按值 O(n)（无序），有序可二分 O(logn)
- **嵌入式要点**：编译期确定大小用静态数组；变长用柔性数组（见 `10-C语言.md` 1.11）或 `malloc(sizeof(T)*n)`

```c
int a[10];              // 10 个 int，sizeof = 40
int *p = a;             // p[3] 等价 *(p+3)
int b[3][4];            // 行主序：b[i][j] 地址 = 基址 + (i*4+j)*sizeof(int)
```

## 1.2 链表 ★★
```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 单链表：只能单向遍历
// 双向链表：有 prev，可反向遍历，删除节点 O(1)
// 循环链表：尾节点 next 指向头，适合轮询调度
```

| | 数组 | 链表 |
|---|---|---|
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n) | O(1)（已定位节点） |
| 内存 | 连续，需一次分配 | 分散，逐个分配 |
| 缓存友好 | 好 | 差（cache miss 多） |
| 碎片 | 无外部碎片 | 有 |

**嵌入式**：链表的节点常用静态数组预分配（内存池），避免 malloc。

## 1.3 栈 ★
- **LIFO**（后进先出），只在栈顶操作
- 数组实现 or 链表实现
- **用途**：函数调用栈、表达式求值（中缀转后缀）、括号匹配、DFS、撤销操作

```c
#define MAX 100
typedef struct { int data[MAX]; int top; } Stack;
void push(Stack *s, int v) { if (s->top < MAX) s->data[s->top++] = v; }
int pop(Stack *s) { return s->top > 0 ? s->data[--s->top] : -1; }
```

## 1.4 队列 ★
- **FIFO**（先进先出），入队尾出队头
- **循环队列**（嵌入式最常用，避免元素移动）：
```c
typedef struct {
    uint8_t buf[256];
    volatile uint16_t head;   // 写位置
    volatile uint16_t tail;   // 读位置
} ring_t;
// 判空：head == tail
// 判满：(head + 1) % SIZE == tail    ← 牺牲一个位置
```
- **用途**：任务调度、消息缓冲、BFS、中断与主循环之间的数据传递

## 1.5 哈希表 ★
- 通过哈希函数把 key 映射到数组下标，平均 O(1) 查找
- **冲突解决**：
  - **链地址法**（拉链）：每个桶挂链表，实现简单
  - **开放寻址**：线性探测、二次探测、双重哈希
- **负载因子** = 元素数 / 桶数，过大要扩容（rehash）
- **嵌入式**：链地址法 + 静态预分配节点更可控

## 1.6 二叉树 ★★
```c
typedef struct TreeNode {
    int val;
    struct TreeNode *left, *right;
} TreeNode;
```

### 遍历（必须能默写）
```c
// 前序：根 → 左 → 右
void preorder(TreeNode *r) {
    if (!r) return;
    visit(r);
    preorder(r->left);
    preorder(r->right);
}
// 中序：左 → 根 → 右（BST 中序遍历是升序）
void inorder(TreeNode *r) {
    if (!r) return;
    inorder(r->left);
    visit(r);
    inorder(r->right);
}
// 后序：左 → 右 → 根（释放树用）
void postorder(TreeNode *r) {
    if (!r) return;
    postorder(r->left);
    postorder(r->right);
    visit(r);
}
// 层序：BFS + 队列
void levelorder(TreeNode *r) {
    if (!r) return;
    Queue q; queue_init(&q); queue_push(&q, r);
    while (!queue_empty(&q)) {
        TreeNode *n = queue_pop(&q);
        visit(n);
        if (n->left)  queue_push(&q, n->left);
        if (n->right) queue_push(&q, n->right);
    }
}
```

### 常见题型
```c
// 求深度
int depth(TreeNode *r) {
    if (!r) return 0;
    int l = depth(r->left), rr = depth(r->right);
    return (l > rr ? l : rr) + 1;
}

// 判断是否为 BST（中序遍历应递增；用 prev 记录前驱值判断）
int is_bst(TreeNode *r, long *prev) {
    if (!r) return 1;
    if (!is_bst(r->left, prev)) return 0;
    if (*prev >= (long)r->val) return 0;   // 必须严格递增
    *prev = r->val;
    return is_bst(r->right, prev);
}
// 调用：long prev = LONG_MIN; is_bst(root, &prev);
// 注意：prev 初值要用 LONG_MIN 而不是 0，否则节点值为负数时误判

// 最近公共祖先（LCA，递归）
TreeNode *lca(TreeNode *root, TreeNode *p, TreeNode *q) {
    if (!root || root == p || root == q) return root;
    TreeNode *l = lca(root->left, p, q);
    TreeNode *r = lca(root->right, p, q);
    if (l && r) return root;        // p、q 分居两侧
    return l ? l : r;
}

// 镜像/翻转（递归交换左右）
void mirror(TreeNode *r) {
    if (!r) return;
    TreeNode *t = r->left; r->left = r->right; r->right = t;
    mirror(r->left); mirror(r->right);
}
```

## 1.7 堆（优先队列）★
- **完全二叉树**，用数组存储：节点 i 的左右子是 2i+1、2i+2，父是 (i-1)/2
- **大顶堆**：父 ≥ 子；**小顶堆**：父 ≤ 子
- 取顶 O(1)，插入/删除 O(logn)，建堆 O(n)
- **用途**：Top K、任务优先级、堆排序、定时器（最小堆管理超时）

```c
// 上浮（插入时）
void sift_up(int *h, int i) {
    while (i > 0) {
        int p = (i - 1) / 2;
        if (h[p] <= h[i]) break;
        int t = h[p]; h[p] = h[i]; h[i] = t;
        i = p;
    }
}
// 下沉（删除堆顶时）
void sift_down(int *h, int n, int i) {
    while (1) {
        int l = 2*i+1, r = 2*i+2, m = i;
        if (l < n && h[l] < h[m]) m = l;
        if (r < n && h[r] < h[m]) m = r;
        if (m == i) break;
        int t = h[m]; h[m] = h[i]; h[i] = t;
        i = m;
    }
}
```

## 1.8 平衡 BST（概念）
- BST 查找 O(logn)，但退化成链表时是 O(n)
- 平衡树保证高度 O(logn)：**AVL**（严格平衡，旋转多）、**红黑树**（近似平衡，插入删除更快，`std::map` 用它）
- 插入/查找/删除都是 **O(logn)**

## 模板 1：反转单链表 ★★★（最高频）
```c
// 迭代（O(1) 空间，首选）
Node *reverse(Node *head) {
    Node *prev = NULL;
    while (head) {
        Node *next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}

// 递归（O(n) 栈空间）
Node *reverse_r(Node *head) {
    if (!head || !head->next) return head;
    Node *new_head = reverse_r(head->next);
    head->next->next = head;
    head->next = NULL;
    return new_head;
}
```
时间 O(n)，空间 O(1) / O(n)。

## 模板 2：反转链表 II（反转第 m 到 n 个节点）★

```c
Node *reverse_between(Node *head, int m, int n) {
    Node dummy = {0, head};
    Node *pre = &dummy;
    for (int i = 1; i < m; i++) pre = pre->next;   // pre 停在 m-1
    Node *cur = pre->next;

        cur->next = nxt->next;
        nxt->next = pre->next;
        pre->next = nxt;
    }
    return dummy.next;
}
```

## 模板 3：判断链表有环 + 找入环点 ★★★
```c
// 判环：快慢指针
int has_cycle(Node *h) {
    Node *slow = h, *fast = h;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return 1;
    }
    return 0;
}

// 找入口：相遇后一个回起点，同速前进再相遇即入口
Node *cycle_entry(Node *h) {
    Node *slow = h, *fast = h;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            slow = h;
            while (slow != fast) { slow = slow->next; fast = fast->next; }
            return slow;
        }
    }
    return NULL;
}
```
**原理推导（必会讲）**：设头到入口 a，入口到相遇点 b，环长 L。
慢走 a+b；快走 a+b+kL；又 2(a+b) = a+b+kL → a = kL - b。
即"从起点走 a"≡"从相遇点走 kL-b 回到入口"。所以两指针同速必在入口相遇。

## 模板 4：合并两个有序链表 ★★
```c
Node *merge(Node *l1, Node *l2) {
    Node dummy;                     // 哨兵，省去头节点特判
    Node *tail = &dummy;
    while (l1 && l2) {
        if (l1->data <= l2->data) { tail->next = l1; l1 = l1->next; }
        else                      { tail->next = l2; l2 = l2->next; }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;      // 接上剩余
    return dummy.next;
}
```
时间 O(m+n)，空间 O(1)。

## 模板 9：二分查找 ★★★
```c
int bsearch(int *a, int n, int target) {
    int lo = 0, hi = n - 1;                 // 闭区间 [lo, hi]
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;       // 防溢出，别写 (lo+hi)/2
        if (a[mid] == target) return mid;
        if (a[mid] < target)  lo = mid + 1;
        else                  hi = mid - 1;
    }
    return -1;
}
```
**变体 1：找左边界（第一个 >= target）**
```c
int lower_bound(int *a, int n, int t) {
    int lo = 0, hi = n;                     // 左闭右开 [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < t) lo = mid + 1; else hi = mid;
    }
    return lo;                              // 可能 == n（都比 t 小）
}
```
**变体 2：找右边界（最后一个 <= target）**：对称，`if (a[mid] <= t) lo = mid+1; else hi = mid;` 返回 `lo-1`。

**手写要点**：
- 区间定义清楚（闭/开）→ 循环条件和收缩方式与之匹配
- `mid` 用 `lo + (hi-lo)/2` 防溢出
- 循环结束时 `lo`/`hi` 的含义要明确

## 模板 10：快速排序 ★★
```c
int partition(int *a, int lo, int hi) {
    int pivot = a[lo];                      // 挖坑法
    while (lo < hi) {
        while (lo < hi && a[hi] >= pivot) hi--;
        a[lo] = a[hi];                      // 右边小的填左边坑
        while (lo < hi && a[lo] <= pivot) lo++;
        a[hi] = a[lo];                      // 左边大的填右边坑
    }
    a[lo] = pivot;
    return lo;
}
void quick_sort(int *a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quick_sort(a, lo, p - 1);
    quick_sort(a, p + 1, hi);
}
```
时间：平均 O(nlogn)，最坏 O(n²)（已排序 + 首元素作轴）；空间 O(logn)（递归栈）；**不稳定**。

## 模板 11：归并排序 ★
```c
void merge_sort(int *a, int *tmp, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    merge_sort(a, tmp, lo, mid);
    merge_sort(a, tmp, mid + 1, hi);
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    for (i = lo; i <= hi; i++) a[i] = tmp[i];
}
```
时间 O(nlogn)（最好最坏都是），空间 O(n)，**稳定**。

## 模板 12：冒泡 / 插入 / 选择排序（简单但我一次写对）
```c
// 冒泡（可提前退出）
void bubble(int *a, int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j+1]) { int t = a[j]; a[j] = a[j+1]; a[j+1] = t; swapped = 1; }
        if (!swapped) break;
    }
}
// 插入（对近乎有序的数据很快）
void insertion(int *a, int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j+1] = a[j]; j--; }
        a[j+1] = key;
    }
}
// 选择（交换次数最少）
void selection(int *a, int n) {
    for (int i = 0; i < n - 1; i++) {
        int m = i;
        for (int j = i + 1; j < n; j++) if (a[j] < a[m]) m = j;
        if (m != i) { int t = a[i]; a[i] = a[m]; a[m] = t; }
    }
}
```

## 模板 14：只出现一次的数（异或）★★
```c
int single(int *a, int n) {
    int r = 0;
    for (int i = 0; i < n; i++) r ^= a[i];
    return r;
}
```
原理：`a^a=0`、`a^0=a`，异或满足交换律结合律。

**变体：只出现一次的两个数**
```c
void single_two(int *a, int n, int *x, int *y) {
    int xor_all = 0;
    for (int i = 0; i < n; i++) xor_all ^= a[i];      // 得到 x^y
    int lowbit = xor_all & (-xor_all);                // 取最低位的 1
    *x = *y = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] & lowbit) *x ^= a[i];                 // 按该位分成两组
        else               *y ^= a[i];
    }
}
```

## 模板 19：最大子数组和（Kadane）★

```c
int max_subarray(int *a, int n) {
    int best = a[0], cur = a[0];
    for (int i = 1; i < n; i++) {
        cur = (cur > 0) ? cur + a[i] : a[i];      // 负数贡献就丢掉
```

## 模板 20：斐波那契（三种写法，考查"为什么递归慢"）
```c
// 1. 朴素递归 O(2^n) —— 大量重复计算
int fib_r(int n) { return n < 2 ? n : fib_r(n-1) + fib_r(n-2); }

// 2. 迭代 O(n) / O(1) —— 实际用这个
int fib(int n) {
    if (n < 2) return n;
    int a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) { c = a + b; a = b; b = c; }
    return b;
}

// 3. 记忆化（缓存）—— 递归 + 数组
int memo[100] = {0};
int fib_m(int n) {
    if (n < 2) return n;
    if (memo[n]) return memo[n];
    return memo[n] = fib_m(n-1) + fib_m(n-2);
}
```

## 模板 21：字符串压缩（游程编码）★
```c
/* aabcccccaaa -> a2b1c5a3 */
int compress(const char *s, char *out) {
    if (!s || !*s) { out[0] = 0; return 0; }
    int w = 0;
    for (int i = 0; s[i]; ) {
        int cnt = 1;
        while (s[i+cnt] == s[i]) cnt++;
        out[w++] = s[i];
        w += sprintf(out + w, "%d", cnt);
        i += cnt;
    }
    out[w] = 0;
    return w;
}
```
实测：`aabcccccaaa` → `a2b1c5a3`。

## 模板 22：大小写转换 + 最长公共前缀 ★
```c
void to_upper(char *s) { for (; *s; s++) if (*s >= 'a' && *s <= 'z') *s -= 32; }
void to_lower(char *s) { for (; *s; s++) if (*s >= 'A' && *s <= 'Z') *s += 32; }

/* 最长公共前缀 */
void lcp(char **strs, int n, char *out) {
    if (n <= 0) { out[0] = 0; return; }
    int i = 0;
    while (strs[0][i]) {
        for (int j = 1; j < n; j++)
            if (strs[j][i] != strs[0][i]) { out[i] = 0; return; }
        out[i++] = strs[0][i];
    }
    out[i] = 0;
}
```
实测：`{"flower","flow","flight"}` → `"fl"`。

## 模板 23：二叉树三种非递归遍历 + 层次遍历 ★★
```c
typedef struct TreeNode { int val; struct TreeNode *left, *right; } TreeNode;

/* 前序：根左右（栈：先压右后压左） */
void preorder_iter(TreeNode *root) {
    TreeNode *st[100]; int top = 0;
    if (!root) return;
    st[top++] = root;
    while (top) {
        TreeNode *n = st[--top];
        visit(n);
        if (n->right) st[top++] = n->right;
        if (n->left)  st[top++] = n->left;
    }
}

/* 中序：左根右（一路压左，弹出访问后转右） */
void inorder_iter(TreeNode *root) {
    TreeNode *st[100]; int top = 0;
    TreeNode *cur = root;
    while (cur || top) {
        while (cur) { st[top++] = cur; cur = cur->left; }
        cur = st[--top];
        visit(cur);
        cur = cur->right;
    }
}

/* 后序：左右根（双栈法，最简单） */
void postorder_iter(TreeNode *root) {
    TreeNode *s1[100], *s2[100]; int t1 = 0, t2 = 0;
    if (!root) return;
    s1[t1++] = root;
    while (t1) {
        TreeNode *n = s1[--t1];
        s2[t2++] = n;
        if (n->left)  s1[t1++] = n->left;
        if (n->right) s1[t1++] = n->right;
    }
    while (t2) visit(s2[--t2]);
}

/* 层次：队列 */
void levelorder(TreeNode *root) {
    TreeNode *q[100]; int head = 0, tail = 0;
    if (!root) return;
    q[tail++] = root;
    while (head < tail) {
        TreeNode *n = q[head++];
        visit(n);
        if (n->left)  q[tail++] = n->left;
        if (n->right) q[tail++] = n->right;
    }
}
```
实测（树 1(2(4,5),3(6))）：前序 `1 2 4 5 3 6`、中序 `4 2 5 1 6 3`、后序 `4 5 2 6 3 1`、层次 `1 2 3 4 5 6`。

## 模板 24：矩阵转置 / 螺旋遍历 / 有序矩阵查找 ★
```c
/* 方阵原地转置 */
void transpose(int n, int a[][N]) {
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int t = a[i][j]; a[i][j] = a[j][i]; a[j][i] = t;
        }
}

/* 螺旋打印（四边界收缩） */
void spiral(int m, int n, int a[][N]) {
    int top = 0, bot = m - 1, left = 0, right = n - 1;
    while (top <= bot && left <= right) {
        for (int j = left; j <= right; j++) printf("%d ", a[top][j]);
        top++;
        for (int i = top; i <= bot; i++) printf("%d ", a[i][right]);
        right--;
        if (top <= bot) { for (int j = right; j >= left; j--) printf("%d ", a[bot][j]); bot--; }
        if (left <= right) { for (int i = bot; i >= top; i--) printf("%d ", a[i][left]); left++; }
    }
}

/* 有序矩阵查找（右上角起步，每步排除一行或一列） */
int search_matrix(int m, int n, int a[][N], int target) {
    int i = 0, j = n - 1;
    while (i < m && j >= 0) {
        if (a[i][j] == target) return 1;
        if (a[i][j] > target) j--; else i++;
    }
    return 0;
}
```
实测：螺旋 `1..12` 的 3×4 矩阵 → `1 2 3 4 8 12 11 10 9 5 6 7`。

## 模板 25：三道最简 DP（爬楼梯 / 最长递增子序列 / 0-1 背包）★★
```c
/* 爬楼梯：f(n) = f(n-1) + f(n-2) */
int climb(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2, c;
    for (int i = 3; i <= n; i++) { c = a + b; a = b; b = c; }
    return b;
}

/* 最长递增子序列 O(n^2)：dp[i] = 以 i 结尾的 LIS 长度 */
int lis(int *a, int n) {
    int dp[100], best = 1;
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
        for (int j = 0; j < i; j++)
            if (a[j] < a[i] && dp[j] + 1 > dp[i]) dp[i] = dp[j] + 1;
        if (dp[i] > best) best = dp[i];
    }
    return best;
}

/* 0-1 背包：倒序枚举容量，保证每件物品只用一次 */
int knapsack(int *w, int *v, int n, int cap) {
    int dp[101] = {0};
    for (int i = 0; i < n; i++)
        for (int c = cap; c >= w[i]; c--)          /* 倒序！ */
            if (dp[c - w[i]] + v[i] > dp[c]) dp[c] = dp[c - w[i]] + v[i];
    return dp[cap];
}
```
实测：`climb(5)=8`；`{10,9,2,5,3,7,101,18}` 的 LIS = 4；`w={1,3,4,5}, v={1,4,5,7}, cap=7` → 9。

**DP 三件套**（任何 DP 题都按这个想）：① 状态定义（dp[i] 表示什么）② 转移方程 ③ 边界与遍历顺序。

# 第三部分：题目（20 题，答案已给）

### Q1 ★★★ 反转单链表（迭代 + 递归），说复杂度。
**答案**：见模板 1。迭代时间 O(n) 空间 O(1)；递归时间 O(n) 空间 O(n)（调用栈）。
边界：空链表返回 NULL；单节点返回自身。

### Q2 ★★★ 判断链表有环，并找入环点，说明原理。
**答案**：见模板 3。原理用"快慢指针速度差 + a = kL-b"推导。

### Q3 ★★ 合并两个有序链表。
**答案**：见模板 4。用哨兵节点 dummy 省去头节点特判，时间 O(m+n) 空间 O(1)。

### Q4 ★ 删除链表倒数第 n 个节点，要求一趟遍历。
**答案**：见模板 5。快慢指针间隔 n+1，快指针到头时慢指针在待删节点的前一个。

### Q5 找链表中点，偶数个时返回哪个？
**答案**：见模板 6。快慢指针，`while (fast && fast->next)` 时偶数个返回**后中点**；若写 `while (fast->next && fast->next->next)` 则返回前中点。

### Q6 ★ 判断回文链表。
**答案**：见模板 7。思路：快慢指针找中点 → 反转后半段 → 逐个比较。要求 O(1) 空间。

### Q7 ★★ 二分查找，并说明为什么 mid 要写 lo+(hi-lo)/2。
**答案**：见模板 9。`lo+hi` 在 lo、hi 都很大时可能溢出 int；`lo+(hi-lo)/2` 避免溢出。
边界：闭区间用 `lo <= hi`，左闭右开用 `lo < hi`。

### Q8 ★ 二分查找的变体：找第一个大于等于 target 的位置。
**答案**：见模板 9 变体 1。关键是 `if (a[mid] < t) lo = mid+1; else hi = mid;`，返回 lo（可能等于 n）。

### Q9 ★★ 手写快排的 partition，说明时间复杂度。
**答案**：见模板 10。挖坑法：pivot 挖出，右边找小的填左坑，左边找大的填右坑，最后 pivot 归位。
平均 O(nlogn)，最坏 O(n²)（已排序数据 + 首元素作轴），空间 O(logn)（递归栈），不稳定。

### Q10 ★ 归并排序相比快排的优势？
**答案**：① 稳定 ② 最坏也是 O(nlogn)（快排最坏 O(n²)） ③ 适合链表排序（不需要随机访问）。
劣势：需要 O(n) 额外空间。

### Q11 ★★ 只出现一次的数（其余出现两次），O(n) 时间 O(1) 空间。
**答案**：见模板 14。全员异或，`a^a=0`，`a^0=a`。

### Q12 ★ 只出现一次的两个数，怎么找？
**答案**：见模板 14 变体。先全员异或得到 x^y，取最低位的 1 作为分组依据，两组分别异或。

### Q13 两个栈实现队列，说明复杂度。
**答案**：入队压 s1（O(1)）；出队时若 s2 为空，把 s1 全部倒入 s2 再弹（均摊 O(1)）。
均摊分析：每个元素最多进 s1 一次、移入 s2 一次、弹出一次 → 总 O(n)，均摊 O(1)。

### Q14 ★ 数组中删除重复元素（有序数组，原地），返回新长度。
**答案**：见模板 17。双指针：w 写指针，r 读指针，不同则写入并前移。

### Q15 ★ 有序数组找两数之和等于目标，O(1) 空间。
**答案**：见模板 18。左右指针夹逼：和太小左指针右移，太大右指针左移。

### Q16 ★ 最大子数组和。
**答案**：见模板 19（Kadane）。状态定义：`cur` = 以 i 结尾的最大和；转移：`cur = max(cur+a[i], a[i])`。

### Q17 ★ 斐波那契为什么朴素递归慢？怎么优化？
**答案**：朴素递归 O(2^n)——同一个子问题被重复计算（fib(5) 算了多次 fib(3)）。
优化：① 迭代 O(n)/O(1) ② 记忆化（缓存已算结果）O(n)/O(n)。

### Q18 ★ 二叉树的中序遍历，递归和非递归两种写法。
**答案**：递归见 1.6；非递归用显式栈：
```c
void inorder_iter(TreeNode *r) {
    TreeNode *stack[100]; int top = 0;
    while (r || top > 0) {
        while (r) { stack[top++] = r; r = r->left; }   // 一路向左压栈
        r = stack[--top];
        visit(r);                                       // 访问
        r = r->right;                                   // 转右子树
    }
}
```

### Q19 ★ 求二叉树深度 / 判断两棵树是否相同。
**答案**：
```c
int depth(TreeNode *r) { if (!r) return 0; int l=depth(r->left), rr=depth(r->right); return (l>rr?l:rr)+1; }
int same(TreeNode *a, TreeNode *b) {
    if (!a && !b) return 1;
    if (!a || !b) return 0;
    return a->val == b->val && same(a->left,b->left) && same(a->right,b->right);
}
```

### Q20 ★ 用数组实现一个最小堆，说明插入和取最小值的过程。
**答案**：见 1.7。插入：放到数组末尾 → 上浮（与父比较交换）O(logn)；取最小：取堆顶 → 末尾元素移到堆顶 → 下沉 O(logn)；建堆 O(n)（从最后一个非叶节点向前下沉）。

## 排序算法
| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定 |

**怎么选**：
- 要稳定 → 归并
- 要原地且平均最快 → 快排
- 要最坏也 O(nlogn) → 归并/堆排
- 数据近乎有序 → 插入排序
- 数据范围小 → 计数排序
