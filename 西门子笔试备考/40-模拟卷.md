# 参考答案（做完再看）

## T1
(1) 用 `xSemaphoreGiveFromISR` / `xTaskNotifyFromISR` 等 FromISR 版本。普通 API 在中断上下文可能阻塞或操作调度数据结构不安全；FromISR 版本不阻塞，并通过 `xHigherPriorityTaskWoken` 参数告知需要任务切换（退出时 `portYIELD_FROM_ISR`）。
(2) 互斥锁。二值信号量无所有权概念（A 也能给 B 加的锁解锁）、无优先级继承；互斥锁有所有权且带优先级继承，专为保护临界资源设计。
(3) 出现**优先级反转**：C 持锁 → B 等锁阻塞 → 中优先级任务抢占 C，B 被间接压住。FreeRTOS 互斥锁带**优先级继承**：C 持锁期间被临时提升到 B 的优先级，尽快跑完释放锁。

## T2
起始：SCL 高时 SDA 由高变低；停止：SCL 高时 SDA 由低变高。数据有效：SCL 高电平期间 SDA 必须稳定，SDA 只能在 SCL 低电平期间变化——因为高电平期间的变化被定义为起始/停止信号，若数据位在此时翻转，接收方会误判为起始/停止。两个主机同时发：线与仲裁，都发 1 实际读到 0 的主机退出（ID 数值小者赢），非破坏性，输方自动变接收方稍后重试。

## T3
(1) TCP 是字节流，无消息边界，可能一次读到多条（或半条）；UDP 保留报文边界，一次 sendto 对应一次 recvfrom。
(2) ① 固定长度命令（浪费、不灵活）；② 分隔符（命令含二进制数据时不可靠）；③ **长度前缀**（header 写 body 长度）——命令流协议最合适，能区分边界且支持二进制。
(3) TCP。重传保证不丢、序列号保证有序；UDP 需要自己在应用层实现确认/重排/超时，等于重造 TCP。

## T4
(1) 硬实时：deadline 错过即失败，如安全气囊点火、电机控制；软实时：偶尔超时可接受，如视频解码。
(2) 看门狗在程序跑飞/死循环时复位系统。错在：若只让一个任务喂狗，其他任务卡死时狗照常被喂，系统永远不复位。正确：每个关键任务报告存活，全部正常才喂（多任务协同喂狗）。

## T5
(1) sizeof(str)=6（含 '\0'），strlen(str)=5
(2) sizeof(p)=8（64 位指针），sizeof("world")=6（字面量数组类型含 '\0'）
(3) str 是栈上数组（内容从常量区拷贝）；p 是栈上指针，指向常量区 "world"；"hello"/"world" 字面量在 .rodata 常量区。

## T6
(1) ① 中断与主程序共享变量 ② 硬件寄存器映射 ③ 多任务共享标志。
(2) 编译器可能优化成只读一次寄存器（缓存到寄存器），死循环出不去。`reg` 应声明为 `volatile int *reg`。
(3) 不能。volatile 只禁优化，不保证原子性。例：32 位系统上对 volatile 64 位变量的自增，两条指令之间可被打断。

## T7
(1) A：1+3(填充)+4+1+3(填充)=12；B：4+1+1+2(填充)=8；C：1+1(填充)+2+1+1(填充)=6。
    C 详解：a 占 offset 0；b 需 2 字节对齐 → 填充 1 字节、offset 2；c 在 offset 4；总 5 字节，对齐到最大成员 short(2) 的整数倍 → **6**。
(2) 成员按大小**降序**排列最省内存（B 比 A 少 4 字节）。
(3) pack(1) 后 A=6。代价：成员可能未对齐，某些架构（如老 ARM）访问未对齐地址会出错或变慢。

## T8
(1) new 调构造函数/malloc 不调；new 失败抛异常/malloc 返回 NULL；new 类型安全无需强转；new 可重载。
(2) delete 基类指针时，若析构非虚，只调用基类析构，派生类析构不执行 → 派生类资源泄漏。
(3)
```cpp
class Interface {
public:
    virtual ~Interface() = default;
    virtual void run() = 0;
};
```

## T9
① `get_msg` 返回栈数组地址——函数返回后失效（悬空指针）；改：static/堆分配/调用方传入缓冲区。
② `memcpy(dst, src, 20)` 越界——只分配了 10 字节。
③ `free(src)` 后使用 `src`（比较 NULL）——use-after-free；free 后应置 NULL。
④ 未检查 malloc 返回值（可能为 NULL，memcpy 即崩溃）。
⑤ dst 与 src 同一块内存，memcpy 无意义（逻辑问题）。

## T10
(1)
```c
struct node *merge(struct node *l1, struct node *l2){
    struct node dummy; struct node *tail=&dummy;
    dummy.next=NULL;
    while(l1 && l2){
        if(l1->val <= l2->val){ tail->next=l1; l1=l1->next; }
        else { tail->next=l2; l2=l2->next; }
        tail=tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}
```
(2) 快慢指针：slow 每次走 1 步，fast 每次走 2 步。若有环，fast 会先进入环并追上 slow（相对速度 1 步/次，一定相遇）；fast 到达 NULL 则无环。
(3) 时间 O(m+n)（每个节点最多经过一次），空间 O(1)（原位拼接）。
(4) 最坏 ~20 万次比较与指针移动（m+n）。已说 O(1) 空间已是渐进最优；若允许 O(n) 空间可转数组排序后重建，但指针操作并不会更少。此问为开放性加分点。
