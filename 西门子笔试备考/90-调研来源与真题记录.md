### A2. 牛客《infinera、西门子嵌入式工程师春招面经》2022-02

**西门子中国研究院笔试题型**：1.5 小时英文卷，尽量英文作答
- 嵌入式领域常识性问题
- C++ 概念性问题
- 编程题 2 道
- debug 题 1 道
笔试后马上三位面试官面试（项目真实性核实 + 技术全面性 + 在校经历）

**infinera 技术面考点**（同批面试，可作为难度参照）：

- Linux 中断底半部机制
- Linux 应用同步和互斥手段
- C++ 如何引用 C 语言程序
- DMA 如何工作

### A3. 牛客《求西门子嵌入式面经（已面完）》2022-09

- 第一页：各种总线协议、RAM 和 ROM

## C 级：通用基线（用于兜底"没搜到但大概率考"）

### C1. 牛客《嵌入式 C 语言必备 20 道八股文》2025-07
URL: https://www.nowcoder.com/discuss/910440666369392640
**带高频权重排序**（直接采用）：
1. `volatile` / `const` / `static`：几乎必问，容易追问到中断、寄存器、链接可见性
2. 指针体系：一级/二级/函数指针、指针与数组、野指针/悬空指针
3. 内存布局与对齐：.text/.data/.bss、堆栈、sizeof、#pragma pack
4. 宏、内联、常量定义：编译期行为、副作用、类型检查
5. 嵌入式约束题：ISR 规范、malloc 风险、大小端、位操作、可重入

20 题清单：volatile、static、const/#define/enum、指针与数组、sizeof/strlen、堆栈与少用 malloc、野指针/悬空指针、结构体对齐、#pragma pack 利弊、位运算、函数指针、二级指针、const 指针三种写法、宏与内联、内存泄漏、ISR 注意、内存分段、大小端、位域、typedef + 函数指针

### C2. 牛客《春招嵌入式面经汇总（被问烂的题）》2025
URL: https://www.nowcoder.com/discuss/902486275725279232
六模块：
- C 语言（最高频）：volatile/static/extern/const vs #define/#define vs typedef/##/sizeof vs strlen/inline/指针引用/大小端判断/内存分区/编译四过程
- 单片机 STM32：主频与性能、GPIO/中断/定时器、波特率计算、中断不能太长、IIC/SPI/UART 区别
- 操作系统 Linux：进程线程（内核/内存角度）、线程调度、fork 写时复制、IPC 方式、共享内存为何快、虚拟内存/页表/TLB/缺页、临界区、程序启动流程、实时 vs 非实时 OS
- 数据结构算法：栈队列链表、判环找入口、异或找单数、手写反转链表（递归+非递归）、链表平移
- 通信协议：CAN 帧结构、DMA 解析数据、跨平台协议设计、CRC 校验
- RTOS/FreeRTOS：调度、任务状态、上下文切换保存什么、二值信号量 vs 互斥锁、**优先级反转与优先级继承**、heap_4、portYIELD_FROM_ISR、多线程喂狗

### C3. 电子工程专辑《嵌入式 5 大通信接口，时序图讲透》2026-09
URL: https://www.eet-china.com/mp/a525531.html
UART/I2C/SPI/CAN/USB 的时序细节、开漏上拉、CPOL/CPHA、CAN 仲裁与位填充、调试方法

### C4. 华为云《嵌入式软件工程师笔试面试指南-网络编程》2022

### C5. 博客园《我的第一次嵌入式软件工程师笔试复盘》2025-01
