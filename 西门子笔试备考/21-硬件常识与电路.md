# 第一部分：基础元件

### 1.1 电阻 / 电容 / 电感 ★★（西门子真题）
| 元件 | 作用 | 嵌入式中的典型用法 |
|---|---|---|
| **电阻 R** | 限流、分压、上拉/下拉、采样 | LED 限流、按键上拉、分压测电压、电流采样 |
| **电容 C** | 储能、**滤波/去耦**、隔直通交、定时 | 电源旁路、RC 滤波、RC 延时、耦合隔直 |
| **电感 L** | 通直流阻交流、储能、滤波 | 与电容组 LC 滤波、DC-DC 电源、共模电感 |

**必答的物理直觉** ★：
- 电容两端**电压不能突变**（要先充放电）→ 所以能做滤波、延时、去耦
- 电感中**电流不能突变**（会产生反电动势）→ 所以断电时会有高压尖峰，需要续流保护

### 1.2 上拉 / 下拉电阻 ★★
| | 作用 | 典型场景 |
|---|---|---|
| **上拉（Pull-up）** | 把悬空引脚拉到高电平（默认确定状态） | 按键（按下接地变低）、**I2C 开漏必需**、复位脚、片选 |
| **下拉（Pull-down）** | 把引脚拉到低电平 | 按键（按下接高）、使能脚默认关闭 |

**为什么必须要有？** ★★
CMOS 输入**悬空时电平不确定**，会因噪声震荡 → 功耗上升、误触发、甚至损坏。所以每个输入脚都必须有确定的默认电平。

**阻值选择**：常用 4.7kΩ ~ 10kΩ。阻值小 → 抗干扰强但功耗大；阻值大 → 省电但易受干扰。
**I2C 的上拉取值**（100k→4.7kΩ，400k→2.2kΩ）见 `20-总线与接口时序.md` 2.2。

### 1.3 电容的种类与用途（了解）
| 类型 | 特点 | 用途 |
|---|---|---|
| 陶瓷电容（MLCC） | 小容值、高频好、无极性 | **去耦、高频滤波**（0.1μF 标配） |
| 电解电容 | 大容值、有极性、高频差 | **电源储能/低频滤波**（10μF、100μF） |
| 钽电容 | 中大容值、稳定 | 电源滤波（注意耐压余量） |
| 薄膜电容 | 稳定、精度高 | 定时、采样 |

**标准配置**：大电容（10μF 电解）+ 小电容（0.1μF 陶瓷）**并联** —— 大电容滤低频纹波，小电容滤高频噪声。

# 第二部分：常见外围电路

### 2.1 按键电路与消抖 ★★★（经典题）
**问题**：机械触点闭合瞬间会弹跳（bounce），产生 **10~20ms** 的多次通断，程序会误判为多次按键。

| 方式 | 做法 | 优缺点 |
|---|---|---|
| **硬件消抖** | ① RC 低通滤波（10kΩ + 0.1μF）② RS 触发器（双稳态） | 不占 CPU；增加成本与面积 |
| **软件消抖** | ① 检测到电平变化后**延时 10~20ms 再读一次**，仍为同一电平才确认 ② 定时器每 10ms 采样，连续 N 次一致才确认 | 零成本，最常用；阻塞延时占 CPU，定时器法不阻塞 |

**软件消抖代码**：
```c
// 简单版（阻塞）
if (read_key() == 0) {
    delay_ms(15);                    // 等抖动过去
    if (read_key() == 0) { /* 确认按下 */ }
}

// 定时器扫描版（不阻塞，推荐）
static uint8_t cnt = 0, stable = 1;
void tick_10ms(void) {                 // 每 10ms 调用
    uint8_t now = read_key();
    if (now != stable) {
        if (++cnt >= 3) { stable = now; cnt = 0; /* 状态稳定 */ }
    } else cnt = 0;
}
```

**上拉/下拉的选择**：按键接 GND 用**上拉**（平时高、按下低）；接 VCC 用**下拉**。

### 2.2 去耦电容 ★★
**做法**：每个芯片的**电源脚旁**放 **0.1μF（100nF）** 电容到地，**距离越近越好**（几毫米内）。

**作用**：
1. 滤掉电源上的高频噪声，给芯片干净电源
2. 芯片瞬态取电时提供"本地水库"，避免电源瞬间跌落

**为什么是 0.1μF**：这个容值对 MHz 级的高频噪声阻抗最低（自谐振频率附近），是几十年工程实践的标准值。更大的容值对低频纹波有效但对高频来不及响应。

**布局要点**：电容 → 芯片电源脚 → GND 的回路面积要小（回路面积大 = 寄生电感大 = 高频失效）。

### 2.3 LED 限流
```
R = (Vcc - Vf) / I
例：5V 供电，红色 LED Vf ≈ 2V，电流 10mA
R = (5 - 2) / 0.01 = 300Ω → 取 330Ω（标准值）
```
**要点**：LED 必须串限流电阻，直接接电源会烧；单片机 IO 驱动能力有限（通常 20mA 以内/脚，总电流有上限）。

### 2.4 三极管与 MOS 管驱动 ★（了解）
| | 三极管（BJT） | MOS 管（MOSFET） |
|---|---|---|
| 控制量 | **电流**（Ib 驱动） | **电压**（Vgs 驱动） |
| 类型 | NPN / PNP | N 沟道 / P 沟道 |
| 驱动功率 | 较小 | 大 |
| 开关速度 | 慢（有存储时间） | 快 |
| 功耗 | 有持续基极电流 | 栅极几乎不耗电 |
| 典型用途 | 小信号放大、小负载开关 | 大电流开关、电机、电源 |

**NPN 做低边开关**：基极串限流电阻接 MCU，集电极接负载，发射极接地。
**N-MOS 做低边开关**：栅极接 MCU（经电阻），漏极接负载，源极接地。注意 Vgs 要足够（逻辑电平 MOS 才能在 3.3V 完全导通）。

### 2.5 继电器与 H 桥
**继电器**：电磁线圈 + 机械触点，可控制大电流/高压，但与 MCU **电气隔离**。
- 驱动需要三极管/MOS + **续流二极管**（线圈是感性负载）
- 缺点：机械寿命有限（10 万~1000 万次）、动作慢（ms 级）、有触点抖动

**H 桥**：四个开关组成 H 形，控制电机正反转。
- 状态：左上+右下导通 = 正转；右上+左下导通 = 反转；同侧导通 = **短路（禁止！）**
- 死区时间：切换方向时必须先全关再开另一侧，防止直通短路
- 常用集成 H 桥芯片：L298N、TB6612、DRV8833

### 2.6 感性负载断电保护 ★★★（西门子真题）
**问题**：感性负载（继电器线圈、电磁阀、电机）断电瞬间，电感 **L·di/dt** 产生**反向高压尖峰**（可达几百伏），会击穿驱动三极管/MOS。

**解决方案**（按常用度）：
| 方案 | 做法 | 特点 |
|---|---|---|
| **续流二极管** ★ | **反向并联**在线圈两端（正常时截止，断电时导通给电流回路） | 最常用、最便宜 |
| RC 吸收 | 电容+电阻串联并在线圈两端 | 也能抑制 dv/dt |
| TVS 管 | 瞬态电压抑制，快速钳位 | 快，成本较高 |
| 稳压管 | 限制反压幅度 | 简单 |

**续流二极管方向**（必考）：
```
      VCC
       │
       ├──────┐
       │      │
     [线圈]  [二极管]  ← 阴极接 VCC，阳极接驱动管
       │      │         （正常时反偏截止）
       ├──────┘
       │
    [驱动管] → GND
```
**一句话答案**："电磁阀断开时线圈储能需要释放，反向并联续流二极管提供泄放回路，避免反向高压击穿驱动管。"

### 2.7 电平转换
3.3V MCU 接 5V 器件的几种方法：
| 方法 | 说明 |
|---|---|
| 电阻分压 | 5V→3.3V 方向简单（但速度慢） |
| 专用电平转换芯片 | TXS0108、TXB0108，双向自动 |
| MOS 管电平转换 | 一个 MOS + 两个上拉，双向 |
| 开漏 + 上拉 | I2C 天然支持（都拉到 3.3V） |

**铁律**：3.3V 器件输入 5V 信号可能烧毁（看数据手册的绝对最大额定值）；5V 器件输入 3.3V 可能识别不到高电平（VIH 门槛）。

# 第三部分：模拟与电源

### 3.1 ADC ★★
**分辨率**：位数决定能区分多少级。
- 12 位 → 4096 级（STM32 常见）
- 10 位 → 1024 级
- 16 位 → 65536 级（外部 ADC 常见）

**转换公式**：
```
数字值 = (Vin / Vref) × (2^n - 1)
Vin = 数字值 × Vref / (2^n - 1)
例：12 位 ADC，Vref=3.3V，读到 2048 → Vin = 2048 × 3.3 / 4095 ≈ 1.65V
```

**采样时间的影响** ★：采样时间越长 → 对信号积分越充分 → 抗干扰强、精度高，但转换速度慢（采样率低）。
**其他考点**：
- 参考电压（Vref）稳定性直接决定精度
- 输入阻抗：高阻信号源需要加缓冲运放
- 差分输入 vs 单端输入
- 过采样可提升有效位数（累加平均）

### 3.2 DAC
数字 → 模拟电压输出，用于音频、波形生成、模拟量控制。
- 分辨率同理（12 位 DAC 输出 4096 级电压）
- 输出建立时间（settling time）影响最高输出频率

### 3.3 PWM ★★
**原理**：通过占空比（duty cycle）控制输出的平均电压。
```
Vavg = Vcc × duty
例：5V 供电，50% 占空比 → 平均 2.5V
```
**用途**：
- 电机调速（占空比决定转速）
- LED 调光（人眼视觉暂留）
- 舵机控制（**固定 50Hz，脉宽 0.5~2.5ms 对应角度**）
- DAC 替代（低通滤波后得到模拟电压）

**参数**：频率、占空比、分辨率（定时器位数）。
**坑**：电机 PWM 频率要选对（太低有噪音和抖动，太高开关损耗大，常用 10~20kHz）。

### 3.4 4-20mA 电流环 ★★★（西门子模拟量必考）
**工业标准**：4mA = 量程下限，20mA = 量程上限。

**为什么从 4mA 开始，而不是 0mA？** ★★（核心考点）
→ **"活零点"设计**：0mA 无法区分"信号为最小值"和"线路断线/传感器故障"；而正常工作时电流永远 ≥4mA，所以 **<4mA（尤其接近 0）一定是断线故障**，可被检测。

**为什么用电流不用电压？** ★
电流环在长距离传输中**不受线路电阻压降影响**（串联回路电流处处相等），抗干扰强，适合工业现场。

**西门子模拟量模块的换算** ★：
- 4~20mA 线性映射为 **0~27648**（16 位整数的典型满量程值）
- 读数 X → 电流 = 4 + (X / 27648) × 16 mA
- 例：读到 13824（= 27648/2）→ 电流 = 4 + 8 = **12mA**（量程中点）
- 例：读到十六进制 1FFF（= 8191）→ 电流 = 4 + (8191/27648)×16 ≈ **8.74mA**

### 3.5 负载类型 ★★（西门子真题）
| 类型 | 电流与电压关系 | 例子 | 注意 |
|---|---|---|---|
| **阻性** | 同相 | 白炽灯、电热丝、电阻炉 | 最简单，无特殊处理 |
| **感性** | 电流**滞后**电压 | 电机、变压器、继电器、电磁阀 | **断电产生反电动势**，需续流保护 |
| **容性** | 电流**超前**电压 | 补偿电容、电容负载 | 通电瞬间大冲击电流（需限流） |

**为什么这样**：电感阻碍电流变化 → 电流跟不上电压；电容阻碍电压变化 → 电流先于电压。

### 3.6 电源基础
| 类型 | 特点 | 效率 |
|---|---|---|
| **LDO**（线性稳压） | 简单、低噪声、无 EMI；压差大时发热严重 | 低（= Vout/Vin） |
| **DC-DC**（开关电源） | 效率高（85~95%）、可升压/降压；有开关噪声 | 高 |
| **Buck**（降压） | 输出 < 输入 | 高 |
| **Boost**（升压） | 输出 > 输入 | 高 |
| **Buck-Boost** | 可升可降 | 高 |

**LDO 发热计算**：`P = (Vin - Vout) × I`
例：12V 降到 3.3V，电流 500mA → P = (12-3.3)×0.5 = 4.35W（太多，必须用 DC-DC）

### 3.7 保护电路
| 保护 | 器件 | 防什么 |
|---|---|---|
| 过流 | 保险丝、自恢复保险（PTC） | 短路、过载 |
| 过压 | **TVS**、压敏电阻 | 浪涌、静电 |
| 反接 | 二极管、MOS 防反接电路 | 电源接反 |
| ESD | ESD 二极管、TVS | 静电放电（人体模型 ±8kV） |
| 滤波 | 共模电感、磁珠 | EMI 传导干扰 |
| 欠压/过压检测 | 电压监测 IC | 电池过放 |

### 3.8 时钟与晶振 ★
| 类型 | 精度 | 用途 |
|---|---|---|
| **晶振（XTAL）** | ±10~50 ppm | 主时钟（需外部电容） |
| **陶瓷谐振器** | ±0.5% | 低成本场合 |
| **内部 RC 振荡器（HSI）** | ±1~5% | 快速启动、低成本，但精度差 |
| **RTC 晶振（32.768kHz）** | ±20 ppm | 实时时钟（32768 = 2^15，便于分频到 1Hz） |

**为什么 RTC 用 32.768kHz**：2^15 = 32768，15 级二分频正好得到 1Hz 秒脉冲，硬件实现简单。
**时钟树**：MCU 内部有 PLL（锁相环）把低频晶振倍频到高频系统时钟（如 8MHz → 180MHz），再分频给各外设（AHB/APB 总线）。

# 第四部分：控制算法（工业场景）

### 4.1 PID 控制 ★★★
| 项 | 作用 | 参数过大的后果 | 参数过小的后果 |
|---|---|---|---|
| **P 比例** | 按当前误差成比例输出，决定**响应速度** | 振荡、超调 | 响应慢、稳态误差大 |
| **I 积分** | 累加历史误差，**消除稳态误差** | 超调、**积分饱和** | 稳态误差消不掉 |
| **D 微分** | 按误差变化率，**抑制超调、增加阻尼** | 放大噪声、抖动 | 超调大、振荡 |

**公式（位置式）**：
```
output = Kp·e(k) + Ki·Σe(k) + Kd·[e(k) - e(k-1)]
```
**增量式**：
```
Δoutput = Kp·[e(k)-e(k-1)] + Ki·e(k) + Kd·[e(k)-2e(k-1)+e(k-2)]
```

### 位置式 vs 增量式 ★
| | 位置式 | 增量式 |
|---|---|---|
| 输出 | 直接的控制量 | 控制量的增量 |
| 积分 | 需要累加，可能饱和 | 天然无积分饱和 |
| 适合 | 输出无记忆的执行器（如 PWM 调速） | 有记忆的执行器（如阀门位置） |
| 切换 | 手动/自动切换有冲击 | 切换平滑 |

### 积分饱和（Integral Windup）★
**问题**：误差长时间存在 → 积分项无限累积 → 输出远超执行器能力 → 误差反向时需要很长时间才能把积分降下来 → 大幅超调。
**解决**：
1. **积分限幅（Clamping）**：限制积分项的累计上下限
2. **积分分离**：误差大时不用积分，误差小时才启用
3. **变速积分**：误差越大，积分系数越小
4. **用增量式 PID**：天然无饱和

### 串级 PID（双环）★
```
目标值 → [外环 PID] → 内环目标 → [内环 PID] → 执行器
            ↑                        ↑
        外环反馈                  内环反馈
        (位置/角度)              (速度/角速度)
```
**平衡车例子**：外环角度环（PD），输出目标角速度；内环速度环（PI），输出 PWM。
**整定顺序：先内环后外环**（先把内环调稳，再调外环）。

### 4.2 电机与调速 ★
| 电机 | 特点 | 调速方式 |
|---|---|---|
| **直流有刷** | 最简单、便宜、有电刷磨损 | 调压 / **PWM 斩波**（H 桥正反转） |
| **步进电机** | 开环精确定位、低速大扭矩、高速扭矩下降 | 脉冲频率调速、细分驱动 |
| **无刷直流（BLDC）** | 高效率、长寿命、需电子换向 | 六步换相 / **FOC** 矢量控制 |
| **交流异步** | 结构简单、耐用 | **变频调速 VVVF**（改变频率与电压） |
| **伺服电机** | 高精度、闭环（编码器） | 位置/速度/力矩三环控制 |

### 4.3 同步 vs 异步电机（西门子真题曾考）
- **同步电机**：转子转速 = 旋转磁场转速（n = 60f/p），需要励磁（永磁或电励磁）。效率高、功率因数可调。用于发电机、大功率场合。
- **异步（感应）电机**：转子转速略低于磁场（有**转差率**），靠电磁感应产生转矩。结构简单、成本低、最广泛使用。
- **区别核心**：转速是否与磁场严格同步。

# 第六部分：题目（30 题，答案已给）

## 基础元件

### Q1 ★ 电阻、电容、电感各有什么作用？各举一个嵌入式中的用法。
**答案**：
- 电阻：限流/分压/上拉下拉/采样 → LED 限流、按键上拉、电压采样
- 电容：储能/滤波/去耦/隔直通交/定时 → 电源去耦（0.1μF）、RC 滤波
- 电感：通直流阻交流/储能/滤波 → LC 滤波、DC-DC 储能、共模电感

### Q2 ★★ 为什么输入引脚不能悬空？上拉/下拉解决什么问题？
**答案**：CMOS 输入悬空时电平不确定，会因噪声震荡 → 功耗上升、误触发、可能损坏。
上拉/下拉给引脚一个确定的默认电平（上拉到高、下拉到低），按键、复位脚、片选、I2C 都需要。

### Q3 ★ 电容为什么能滤波？为什么需要大电容和小电容并联？
**答案**：电容两端电压不能突变，充放电时吸收/释放电荷，把电压波动平滑掉。
大电容（10μF）滤低频纹波（电源波动），小电容（0.1μF）滤高频噪声（开关瞬态）——两者的自谐振频率不同，并联覆盖更宽频段。

### Q4 为什么要给 LED 串限流电阻？怎么算？
**答案**：LED 是二极管，正向压降固定，直接接电源电流会急剧增大烧毁。
`R = (Vcc - Vf) / I`，例：5V 供电、Vf=2V、I=10mA → R = 300Ω，取标准值 330Ω。

## 按键与消抖

### Q5 ★★★ 按键为什么需要消抖？硬件和软件分别怎么做？
**答案**：机械触点闭合时弹跳 10~20ms 产生多次通断，程序会误判多次按键。
硬件：RC 低通滤波（10kΩ+0.1μF）或 RS 触发器。
软件：检测变化后延时 10~20ms 再读一次确认；或用定时器每 10ms 采样、连续 3 次一致才确认（不阻塞）。

### Q6 按键接 GND 应该用上拉还是下拉？
**答案**：用**上拉**。这样平时引脚为高电平，按下时接地变低，检测下降沿即可。接 VCC 则用下拉。

### Q7 ★★ 某系统按键偶尔出现"按一次触发两次"，可能是什么原因？
**答案**：① 没有做消抖（或消抖时间不够，小于 10ms）② 中断触发方式配置成双边沿而非单边沿 ③ 机械触点老化抖动加剧 ④ 硬件缺少上拉/滤波，噪声引起误触发。解决：软件消抖 10~20ms、只检测单边沿、加上拉和 RC 滤波。

## 电源与去耦

### Q8 ★★ 去耦电容放在哪？为什么用 0.1μF？
**答案**：放在**芯片电源脚旁边**（越近越好，几毫米内），另一端接 GND。
0.1μF 对 MHz 级高频噪声阻抗最低（接近自谐振频率），是几十年的标准值；大容值对低频有效但对高频来不及响应。

### Q9 ★ LDO 和 DC-DC 的区别？什么时候用哪个？
**答案**：LDO 线性稳压——简单、低噪声、无 EMI，但压差大时发热严重、效率低（= Vout/Vin）；DC-DC 开关电源——效率高（85~95%）、可升压降压，但有开关噪声和 EMI。
选择：小电流、小压差、对噪声敏感（模拟/射频）用 LDO；大电流或大压差用 DC-DC。

### Q10 LDO 发热怎么算？举例。
**答案**：`P = (Vin - Vout) × I`。
例：12V → 3.3V，500mA → P = (12-3.3)×0.5 = 4.35W（严重发热，必须改用 DC-DC）。

## 模拟量

### Q11 ★★ 4-20mA 为什么不用 0-20mA？
**答案**：**活零点**设计。0mA 无法区分"信号最小值"和"断线/传感器故障"；正常工作时电流永远 ≥4mA，所以低于 4mA（尤其接近 0）就一定是故障，可被检测。这是工业标准的故障安全设计。

### Q12 ★★ 西门子模拟量模块读到 13824，对应多少 mA？
**答案**：4~20mA 映射 0~27648。
电流 = 4 + (13824/27648) × 16 = 4 + 8 = **12mA**（量程中点）。

### Q13 ★ 为什么工业现场用电流环而不是电压？
**答案**：电流串联回路中处处相等，**不受线路电阻压降影响**，长距离传输不会因为导线电阻造成信号衰减；同时低阻抗传输抗干扰强。电压传输在长线上会因压降和干扰而失真。

### Q14 ★ 12 位 ADC、Vref=3.3V，读到 2048，输入电压是多少？
**答案**：`Vin = 2048 × 3.3 / (2^12 - 1) = 2048 × 3.3 / 4095 ≈ 1.65V`。
（注意满量程是 4095 不是 4096）

### Q15 ★★ ADC 采样时间对精度有什么影响？
**答案**：采样时间越长，采样保持电容充电越充分、对信号积分效果越好 → **抗干扰强、精度高**；但转换速度变慢（采样率降低）。高阻信号源需要更长采样时间或加缓冲运放。

### Q16 ★ PWM 如何实现电机调速和 LED 调光？占空比 30%、5V 供电的平均电压是多少？
**答案**：通过改变占空比（高电平时间/周期）改变平均电压/功率。
平均电压 = 5V × 30% = **1.5V**。
电机：平均电压决定转速；LED：占空比决定亮度（人眼视觉暂留）。
舵机用固定 50Hz、脉宽 0.5~2.5ms 对应角度。

## 负载与保护

### Q17 ★★★ 感性负载断电时会发生什么？怎么保护？
**答案**：电感中电流不能突变，断电瞬间产生反向高压尖峰（L·di/dt，可达几百伏），会击穿驱动三极管/MOS。
保护：**反向并联续流二极管**（最常用）、RC 吸收、TVS 管、稳压管。

### Q18 ★★ 续流二极管怎么接？为什么是这个方向？
**答案**：**反向并联在线圈两端**——**阴极接电源正极，阳极接驱动管集电极/漏极**。
正常工作时二极管反偏截止不导通；断电瞬间线圈产生反向电压，使二极管正偏导通，给线圈电流提供泄放回路，把尖峰能量消耗在线圈内阻和二极管上。

### Q19 ★ 阻性、感性、容性负载的区别？各举例。
**答案**：阻性=电流电压同相（白炽灯、电热丝）；感性=电流滞后电压（电机、变压器、继电器、电磁阀）；容性=电流超前电压（补偿电容）。
感性需要注意反电动势（续流保护）；容性需要注意通电瞬间冲击电流（限流）。

### Q20 ★ 继电器驱动电路要注意什么？
**答案**：① 线圈是感性负载，必须加**续流二极管** ② MCU IO 驱动能力不足，需要三极管/MOS 或专用驱动芯片 ③ 触点控制高压大电流时注意**电气隔离**和爬电距离 ④ 触点抖动和寿命（10 万~1000 万次）⑤ 吸合/释放时间（ms 级）影响响应速度。

### Q21 H 桥是什么？为什么不能同侧开关同时导通？
**答案**：四个开关组成 H 形，控制电机正反转（对角导通 = 一个方向，另一对角 = 反向）。
同侧（如左上+左下）同时导通 → 电源直接经开关短路到地 → 大电流烧毁器件（这叫"直通"）。
所以换向时必须留**死区时间**（先全关再开另一侧）。

## 时钟与复位

### Q22 ★ RTC 晶振为什么用 32.768kHz？
**答案**：32768 = 2^15，经过 15 级二分频正好得到 1Hz 秒脉冲，硬件分频器实现极简单。且该频率的晶振体积小、功耗低。

### Q23 复位电路一般怎么设计？
**答案**：常见 RC 复位（上拉电阻 + 对地电容，上电时电容充电产生低电平复位脉冲）；
更好的是专用复位芯片（如 MAX809）或内部 BOR（欠压复位），能保证电源不稳定时可靠复位。
按键手动复位：复位脚串电阻接按键到地。

## 控制与电机

### Q24 ★★ PID 三个参数各起什么作用？参数过大会怎样？
**答案**：P 比例按当前误差输出，决定响应速度，过大会振荡/超调；I 积分累加历史误差消除稳态误差，过大会超调/积分饱和；D 微分按误差变化率抑制超调，过大会放大噪声。
记忆：P 管速度，I 消误差，D 抑超调。

### Q25 ★ 什么是积分饱和？怎么解决？
**答案**：误差长期存在时积分项无限累积 → 输出远超执行器能力 → 误差反向时需很久才能退饱和 → 大幅超调。
解决：积分限幅（Clamping）、积分分离（大误差时不积分）、变速积分、改用增量式 PID（天然无饱和）。

### Q26 ★ 位置式 PID 和增量式 PID 的区别？
**答案**：位置式直接输出控制量，需积分累加（可能饱和）；增量式输出控制量的增量，天然无积分饱和，切换平滑。
适用：位置式适合无记忆执行器（PWM 调速）；增量式适合有记忆执行器（阀门位置）。

### Q27 ★ 串级 PID 是什么？为什么先调内环？
**答案**：外环（位置/角度）输出作为内环（速度）的目标，内环输出控制执行器。
先内后外：内环是被外环"使用"的执行机构，内环不稳外环无法稳定；内环响应快，才能及时跟踪外环给的快速变化目标。

### Q28 ★ BLDC 和步进电机的区别？各自怎么调速？
**答案**：BLDC（无刷直流）需要电子换相（霍尔或反电动势检测），效率高寿命长，调速用六步换相或 FOC；步进电机开环定位、低速大扭矩，调速用脉冲频率、细分驱动。
选择：需要高速高效连续旋转用 BLDC；需要低成本精确定位、低速用步进。

### Q29 同步电机和异步电机的区别？
**答案**：同步电机转子的转速与旋转磁场严格相同（n = 60f/p），需要励磁；异步（感应）电机转子转速略低于磁场（有转差率），靠电磁感应产生转矩，结构简单成本低、应用最广。

### Q30 ★★ 一个 IO 口要控制 12V 电磁阀，怎么设计电路？
**答案**：
① MCU IO → 限流电阻 → 三极管/MOS 基极/栅极（低边开关）
② 电磁阀一端接 12V，另一端接三极管集电极/漏极
③ **电磁阀两端反向并联续流二极管**（阴极接 12V，阳极接集电极）
④ 如果电磁阀需要电气隔离或高压，用光耦隔离 + 继电器/MOS
⑤ IO 口加下拉电阻确保默认关断
答题要点：**开关器件 + 续流二极管 + 限流/下拉**三件套。

# 第七部分：背诵口诀（早晚各念一遍）

> **电容电压不能突变，电感电流不能突变。**
> **悬空必震荡，所以要上拉/下拉。**
> **按键抖 10~20ms，延时 10~20ms 再读一次。**
> **去耦 0.1μF 贴电源脚，大并小滤高低频。**
> **4-20mA 的 4 是活零点，断线才能被发现。**
> **感性断电有反压，反并二极管续流。**
> **P 管速度，I 消误差，D 抑超调。**
> **积分饱和：限幅、分离、变速、改增量式。**
> **推挽能高能低不能共线，开漏只能拉低可共线。**
> **RTC 用 32.768k，因为 2^15 分频到 1Hz。**
